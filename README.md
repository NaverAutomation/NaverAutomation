# Naver Blog Auto (v0.3.327)

AI 기반 네이버 블로그 자동화 솔루션입니다. 본 프로젝트는 Supabase 인증을 통한 보안 강화와 Gemini/Ollama를 활용한 지능형 콘텐츠 생성 및 Playwright 기반 포스팅 자동화를 지원합니다.

---

## 🚀 주요 기능

- **다양한 AI 엔진 지원**: Google Gemini (2.5-flash-lite 최적화 사용) 및 Ollama(로컬 LLM)를 통한 원고 생성 및 교정.
- **다중 계정 관리**: 여러 네이버 계정을 등록하고 1일 포스팅 제한 한도(15회) 및 라운드 로빈 방식으로 안정적인 분산 포스팅을 수행합니다.
- **이미지 분할 배분 및 보강**:
  - **대표 사진 순차 분할**: 일괄 예약 시 대표 사진을 글마다 1장씩 순서대로 분할 배분하는 옵션을 제공합니다.
  - **본문 사진 순차 분할**: 일괄 예약 시 본문 사진도 겹치지 않고 글마다 다르게 배분되어 발행됩니다.
  - **Gemini AI 이미지 자동 생성**: 본문 사진을 올리지 않았을 경우, Gemini API가 글의 맥락에 맞는 AI 본문 이미지를 실시간으로 자동 생성하여 업로드합니다.
- **보안 및 유저별 격리**: 사용자의 민감한 정보(네이버 비밀번호, API 키 등)는 암호화 처리되어 로컬 SQLite DB(`naver-auto.db`)에 격리되어 안전하게 보호됩니다.
- **안정적인 Playwright 자동화**: 최신 웹 자동화 엔진(Playwright Chromium)을 사용해 네이버 블로그 에디터 팝업 처리, 제목/본문 입력, 태그 등록 및 최종 발행을 매끄럽게 수행합니다.
- **API 유효성 검증 (Zod)**: 백엔드 API 요청의 신뢰성을 보장하기 위해 Zod 스키마 검증 미들웨어를 도입하여 비정상적인 데이터 유입을 사전에 차단합니다.
- **테스트 환경 구축 (Vitest)**: 독립된 `test/` 디렉토리에 Vitest 테스트 프레임워크를 기반으로 백엔드 검증 로직에 대한 단위 테스트 스위트를 구축하였습니다.

## 📋 사전 준비 사항

- **Node.js**: v24.0.0 이상 권장.
- **Supabase 프로젝트**: 사용자 인증 처리를 위한 Supabase URL 및 API Key.
- **AI API Key**:
  - **Gemini**: Google AI Studio에서 발급받은 API 키.
  - **Ollama (선택 사항)**: 로컬에서 구동 중인 Ollama 엔드포인트.

## 🛠 설치 및 실행 방법

### 의존성 설치 및 브라우저 세팅

1. **저장소 클론 및 이동**:
   ```bash
   git clone https://github.com/NaverAutomation/NaverAutomation.git
   cd NaverAutomation
   ```

2. **의존성 패키지 설치**:
   ```bash
   npm install
   ```
   *(설치 시 Playwright 브라우저 엔진이 자동으로 설치 및 구성됩니다.)*

### 애플리케이션 실행

- **개발 서버 실행 (Vite + Node.js Express)**:
  ```bash
  npm run dev
  ```
- **Electron 데스크톱 앱 실행 (개발용)**:
  ```bash
  cross-env NODE_ENV=development electron .
  ```
- **서버 백엔드 단독 실행**:
  ```bash
  npm run start
  ```
- **Vitest 단위 테스트 실행**:
  ```bash
  npm run test
  ```
- **Biome 코드 스타일 및 린트 검사**:
  ```bash
  npm run check
  ```

## ⚙️ 설정 및 사용법

1. **로그인**: 앱 실행 후 본인의 계정으로 로그인합니다.
2. **설정 (`⚙️ 설정`)**: Gemini API 키 또는 Ollama 설정을 입력합니다.
3. **계정 등록 (`👤 계정 관리`)**: 포스팅에 사용할 네이버 계정(아이디/비밀번호)을 등록합니다.
4. **글 생성 & 관리 (`✍️ 글 생성 & 관리`)**:
   - **AI 초안 생성**: 주제 입력 후 초안 원고 및 이미지를 Gemini로 생성하고 편집하여 타이머 예약을 하거나 즉시 발행합니다.
   - **자동 키워드 예약**: 여러 키워드를 입력해 여러 원고를 일괄 자동 생성하고 배분 옵션을 켠 뒤 대기열에 등록합니다.
   - **수기 직접 작성**: AI 도움 없이 직접 제목, 본문, 대표 이미지 및 태그를 수기 입력하여 발행합니다.
5. **예약 대기열 (`📅 예약 대기열`)**: 예약 대기 중인 목록을 확인하거나 강제 즉시 발행 및 예약을 취소할 수 있습니다.
6. **실시간 로그 (`📊 로그`)**: 스케줄러 상태 및 네이버 발행 진행 단계를 실시간으로 모니터링합니다.
